# Java Static Analysis Coursework

A concise, code-free account of a CS 4683 SpotBugs assignment analyzing warnings in Apache Commons Imaging and Apache Commons Lang. The authored assignment report is identified with the owner's name; this publishing copy summarizes its triage without reproducing Apache source snippets, raw analyzer exports, or dependency code.

`review-summary.md` records six warnings and the student's recommendations. It distinguishes ordinary correctness/robustness concerns from warnings that appeared intentional or guarded. SpotBugs warnings are not presented as confirmed vulnerabilities, and none of the proposed code changes is claimed to have been applied or verified.

The owner confirms this was an individual assignment, wrote the substantive analysis, recalls no restriction against publishing the coursework, and had no employment, sponsorship, work-for-hire, or special institutional ownership arrangement. The staged release contains a paraphrase of the owner's authored report and no identifiable instructor-provided source or template. The original report credits the owner; Apache project names are attribution/context only, and no Apache source excerpt is included. No license is added to the third-party projects discussed.
